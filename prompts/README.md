# PersonalAxis Prompts

This directory contains the system prompts and review templates for AI models integrated with PersonalAxis.

## Platform Setup

PersonalAxis uses a local-first, privacy-conscious approach. Instead of direct API calls, we use **context files** generated by the CLI as "session starters" for custom AI interfaces.

### 1. Daily Coach (Gemini)
- **Tool**: [Google Gemini Gems](https://gemini.google.com/gems)
- **Role**: Daily emotional processing and planning.
- **System Prompt**: [daily_coach_system.md](./daily_coach_system.md)
- **Workflow**:
  1. Run `personalaxis daily-context`.
  2. Start a session in your "Daily Coach" Gem.
  3. Upload `output/context.md`.
  4. At the end of the session, say **"Günü kapat"** to get JSON output.
  5. Run `personalaxis save-journal`.

### 2. Strategic Reviewer (ChatGPT)
- **Tool**: [ChatGPT Custom GPTs](https://chatgpt.com/gpts)
- **Role**: Long-term strategic planning and goal analysis.
- **System Prompt**: [strategic_reviewer_system.md](./strategic_reviewer_system.md)
- **Workflow**:
  1. Run `personalaxis review-context --type weekly --period 2026-W02`.
  2. Start a session in your "PersonalAxis Reviewer" GPT.
  3. Upload `output/weekly_2026-W02_context.md`.
  4. Follow the specific review template from [review_templates/](./review_templates/).
  5. Say **"Değerlendirmeyi tamamla"** to get JSON output.
  6. Run `personalaxis save-review`.

## Language Policy

- **System Prompts**: Written in **English** for precision and better instruction following by LLMs.
- **Dialogue & Output**: Primarily in **Turkish** for user experience and Notion consistency.
- **Data Exchange**: **JSON** format for robust parsing back into Notion.
